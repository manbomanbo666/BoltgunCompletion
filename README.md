# 爆弹枪完美通关助手 · BoltgunCompletion

《战锤 40,000：爆弹枪》一代的独立雷达助手：定位秘密与已确认敌人，并根据**同一次最终结算的击杀率 100% + 秘密全收集**判断是否完美通关。

**普通玩家直接下载运行包，无需编译、安装 Python，也不需要把文件放进游戏目录。**

## 2. 第一次使用

1. **完整解压运行包**到自己有写入权限的文件夹，例如 `D:\Games\BoltgunCompletion`。不要在压缩包中直接运行，也不要只单独取出 EXE。
2. 打开解压后的 `BoltgunCompletion` 文件夹，双击 **`BoltgunCompletion.exe`**。带 `-cli` 的程序是命令行工具，普通使用无需打开。
3. 启动《爆弹枪》一代，可从 Steam 启动，也可点击助手中的 **“启动一代游戏”**。在游戏内手动选择**窗口化或无边框模式**。
4. 检查助手上方的游戏目录。通常会自动识别；如果没有，点击 **“选择游戏”**，选择 Steam 的 `steamapps\common\Boltgun` 文件夹。该文件夹内应包含 `Boltgun\Binaries\Win64\Boltgun-Win64-Shipping.exe`，不要选择到最深层的 `Win64` 文件夹。
5. 游戏启动后，在助手中点击 **“连接游戏”**。等待出现 **“插件数据桥接就绪”**。仅显示“加载器已加载”时仍在等待有效数据。
6. 进入关卡并切回游戏，观察雷达中的秘密、敌人标记和当前区域敌人数。以后每次重新启动游戏，都需要重新点击“连接游戏”。

无需向游戏目录复制 DLL、修改游戏配置或导入存档。游戏操作由玩家完成，助手不自动行走、射击、传送或拾取。

## 3. 雷达怎么看、怎么调整？

敌人范围内显示红色实心标记，范围外使用约 **34×22 像素、带深色描边的红色实心折角箭头**。外圈箭头沿实际方位连续转动，不再限制八个方向；相差小于约 12 度的方向合并，只表示大致方向，不表示敌人数或高低。箭头透明度跟随“敌人标记”。秘密保持金色并持续显示，范围外仍为空心；密集时符号会错开，用细线连接圆周上的真实方向，寻找秘密时以连线端点为准。

游戏内只显示**大雷达和“当前区域敌人”计数**，不显示目标列表、编号或距离数字。中央白色箭头是玩家，雷达向上为面朝方向；可关闭中心箭头，固定居中时会自动隐藏。

| 标记 | 含义 |
| --- | --- |
| 金色 | 秘密 |
| 红色实心圆或上下三角 | 雷达范围内的敌人 |
| 外圈红色折角箭头 | 雷达范围外敌人的大致方位，不表示数量或高低 |
| 实心 | 水平距离在当前雷达范围内，边界也算范围内 |
| 金色空心圆或上下三角 | 范围外秘密；密集时可错开并用连线指示真实方位 |
| 上三角 | 相对较高处：至少高于平层容差（默认 5 米） |
| 下三角 | 相对较低处：至少低于平层容差（默认 5 米） |
| 圆形 | 同高附近：相对高差小于平层容差（默认 5 米） |
| 较暗的秘密标记 | 秘密发现状态尚待核实 |

**三角形只表示相对高度，不代表已识别真实楼层。空心只表示范围外，不表示目标状态待核实。** 雷达不判断墙壁、路线或可通行性。

缺少有效根组件或有限坐标的敌人对象暂不定位、不计入已确认区域敌人数，主窗口提示待核实；恢复有效空间状态后可重新显示，不会因此被视作已死亡。

“当前区域敌人”统计本次有效数据中已确认存活且可定位的敌人，包含已确认但在雷达范围外的目标；不包括尚未加载或未激活波次中的敌人，不能视为整关剩余数。数据超过两秒未更新后，清空目标，计数显示“待核实”。在主菜单、加载或结算时也不显示旧位置。

助手主窗口中可以调整：

- **“雷达范围”**：选择 50／100／250／500 米，游戏内不显示距离数字。
- **“显示悬浮面板”**：勾选显示，取消则隐藏。
- **“允许拖动面板”**：勾选后拖动雷达，调整完成后取消勾选，恢复鼠标穿透。
- **“整体不透明度”**：统一调整整个雷达，0% 完全透明，100% 不透明。
- **“雷达设置…”**：背景、距离圆环、十字线、秘密标记、敌人标记、玩家箭头、敌人数文字可分别调整 0–100%，即时预览，关闭设置窗口后保存。分项仍受整体不透明度影响。
- **“固定屏幕中间”**：让雷达中心对齐游戏窗口客户区中心；没有可用游戏窗口时使用所在屏幕中心。再次点击解除固定，恢复原来的自由位置。固定时禁止拖动并自动隐藏中心箭头。
- **“显示中心箭头”**：自由摆放时可选择是否显示；解除固定后恢复原选择。
- **“平层容差（米）”**：在“雷达设置…”内调整，默认 5 米，范围 0.5～30 米。高差小于容差显示圆形，达到容差显示上下三角。

只想保留标记时，可把背景、距离圆环和十字线设为 0%，秘密、敌人标记设为 100%；若要完全不透明的标记，还需将整体不透明度设为 100%。未确认秘密的标记仍会略暗。

查看击杀与秘密进度、连接状态或**最终结算**时，请切回助手主窗口。雷达仅在游戏或助手位于前台时显示，切到其他程序后隐藏。

## 判定与提示

- 完美通关只取同一次最终结算的击杀率 100% 和秘密全收集。
- 当前已生成敌人的击杀比例仅为进度参考，不能预告最终整关击杀率。
- 雷达按相对方向、水平距离和高低关系绘制，位置可能隔墙或跨楼层，不是可通行路线。
- 未加载区域和未激活波次无法完整追踪；秘密状态待核实时会使用较暗标记，具体警告见助手主窗口。
- 数据超过两秒未更新后，停止将旧内容作为实时提示。
- 历史最高成绩不参与本次最终判定。统计未验证时不输出完美通关结论。

## 独立与卸载

所有插件文件、配置和日志留在插件文件夹，不向游戏目录安装文件，不写游戏配置或存档。
关闭助手只关闭显示面板；完整停止加载器需退出游戏。退出游戏后可删除整个插件文件夹。
更新后如果提示游戏里仍是旧版插件，请重启游戏再连接。不使用热卸载或强行替换运行中的加载器。

从 v0.2.1.0 及更早版本升级：

1. **完全退出游戏和助手**，让旧运行时随游戏退出。
2. 下载并完整解压本版 `win-x64.zip`，将其中 `BoltgunCompletion` 文件夹的全部内容复制到原插件目录并覆盖，不能只换两个 EXE。
3. 保留原目录的 `data/settings.json`；发行包不包含个人配置，不会主动覆盖该文件。
4. 重新启动游戏与助手，点击“连接游戏”，等待“插件数据桥接就绪”。

也可完整解压到新文件夹，在游戏和助手均关闭时将旧目录的 `data/settings.json` 复制到新目录相同位置，再启动使用。不要同时从两个插件目录连接同一个游戏。

仅当你已经安装 0.2.2.6 本地预览运行时，本次 0.2.2.7 才可以关闭助手后只更新两个 EXE。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 解压后找不到 `BoltgunCompletion.exe` | 检查下载的是 `win-x64.zip`，而不是源码包；重新完整解压 |
| 提示“未找到一代游戏主程序” | 通过“选择游戏”选择上文所示的游戏安装根目录 |
| 提示“请先启动一代游戏” | 启动游戏后再点击“连接游戏”；同时只运行一个一代游戏实例 |
| 提示“此游戏版本尚未适配” | 当前游戏构建不在支持范围内；请在 Issues 提供游戏构建号和提示文字 |
| 连接后看不到面板 | 勾选“显示悬浮面板”，切回游戏，并检查是否为窗口化或无边框模式；可勾选“允许拖动面板”在助手前台调整位置 |
| 提示文件缺失或校验失败 | 重新下载并完整解压运行包，保留全部目录结构 |
| 提示无法连接游戏进程 | 确认游戏和助手在同一用户、相同权限级别下运行 |
| 提示已加载其他位置的 UE4SS | 退出游戏，停用其他 UE4SS 加载器后重新启动，再连接本助手 |
| 雷达完全看不见 | 检查“显示悬浮面板”、整体不透明度和雷达设置中的各分项；0% 会完全隐藏对应内容 |
| 中心箭头不显示 | 固定居中时会自动隐藏；自由模式下检查“显示中心箭头”和玩家箭头不透明度 |
| 显示“数据中断”或一直等待有效数据 | 旧数据显示已停止；若加载结束后仍未恢复，退出游戏和助手后重新启动并连接 |

仍有问题，可到 **[Issues](https://github.com/manbomanbo666/BoltgunCompletion/issues)** 提供助手版本、游戏构建号、报错文字和复现步骤。提交日志前请移除其中的个人路径等信息。

## 从源码构建

环境：Windows x64、CPython 3.12 x64、.NET Framework 4.x C# 编译器。构建脚本使用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`。

```powershell
python tools/fetch_dependencies.py
python tools/build.py
python tools/package.py
```

首次获取依赖需要联网。UE4SS 固定为 `3.0.1-1181-g83330635`，下载包通过 SHA256 校验，缓存到 `work/`；缓存可删除并重新生成。构建使用仓库内的关卡元数据，不需要重新扫描游戏文件。

输出位于 `dist/`：

- `BoltgunCompletion/`：可直接运行的插件目录。
- `BoltgunCompletion-0.2.2.7-win-x64.zip`：供用户下载的运行包。
- `BoltgunCompletion-0.2.2.7-source.zip`：干净源码包。
- `SHA256SUMS.txt`：两个压缩包的 SHA256。

已有自动检查保留在源码中，可按需运行：

```powershell
python tests/test_runtime.py
dist/BoltgunCompletion/BoltgunCompletion-cli.exe --selftest
```
