# 爆弹枪完美通关助手 · BoltgunCompletion

《战锤 40,000：爆弹枪》一代的独立悬浮助手：左列找秘密，右列找漏怪，并根据**同一次最终结算的击杀率 100% + 秘密全收集**判断是否完美通关。

**普通玩家直接下载运行包，无需编译、安装 Python，也不需要把文件放进游戏目录。**

## 1. 下载哪个文件？

打开 **[最新版本下载页](https://github.com/manbomanbo666/BoltgunCompletion/releases/latest)**，展开页面底部的 **Assets**，下载：

**[BoltgunCompletion-0.1.0.1-win-x64.zip](https://github.com/manbomanbo666/BoltgunCompletion/releases/download/v0.1.0.1/BoltgunCompletion-0.1.0.1-win-x64.zip)**

| 下载项 | 用途 |

请不要把仓库绿色 **Code → Download ZIP** 当作运行包下载。

适用环境：Windows 64 位、.NET Framework 4.x，以及已安装的《爆弹枪》一代。当前仅适配 **Steam 构建 14893097（UE 4.27.2）**；程序会校验游戏文件，其他构建会提示未适配。内置本体 24 关与剧情 DLC 5 关的位置目录；DLC 需要玩家自行拥有，尚未逐关实机验证。

当前版本 **v0.1.0.1** 修复了参考击杀进度超过 100% 时误报“数据中断”的问题。此时仅将参考百分比标为待核实，秘密和位置仍会持续更新；最终结算判定保持严格校验。

## 2. 第一次使用

1. **完整解压运行包**到自己有写入权限的文件夹，例如 `D:\Games\BoltgunCompletion`。不要在压缩包中直接运行，也不要只单独取出 EXE。
2. 打开解压后的 `BoltgunCompletion` 文件夹，双击 **`BoltgunCompletion.exe`**。带 `-cli` 的程序是命令行工具，普通使用无需打开。
3. 启动《爆弹枪》一代，可从 Steam 启动，也可点击助手中的 **“启动一代游戏”**。在游戏内手动选择**窗口化或无边框模式**。
4. 检查助手上方的游戏目录。通常会自动识别；如果没有，点击 **“选择游戏”**，选择 Steam 的 `steamapps\common\Boltgun` 文件夹。该文件夹内应包含 `Boltgun\Binaries\Win64\Boltgun-Win64-Shipping.exe`，不要选择到最深层的 `Win64` 文件夹。
5. 游戏启动后，在助手中点击 **“连接游戏”**。等待出现 **“插件数据桥接就绪”**。仅显示“加载器已加载”时仍在等待有效数据。
6. 进入关卡并切回游戏，观察悬浮面板中的秘密、击杀和位置提示。以后每次重新启动游戏，都需要重新点击“连接游戏”。

无需向游戏目录复制 DLL、修改游戏配置或导入存档。游戏操作由玩家完成，助手不自动行走、射击、传送或拾取。

## 3. 面板怎么看、怎么调整？

| 面板位置 | 显示内容 |
| --- | --- |
| 顶部 | 连接状态、当前关卡、本次击杀和秘密进度 |
| 左列“秘密” | 最近三个秘密目标的方向、直线距离、高低位置和确认状态 |
| 右列“怪物” | 最近三个已确认敌人的方向、直线距离和高低位置 |
| 最终结算 | 本次结果是否满足击杀率 100% 且秘密全收集 |

助手主窗口中可以调整：

- **“显示悬浮面板”**：勾选显示，取消则隐藏。
- **“允许拖动面板”**：勾选后拖动面板到合适位置；调整完成后取消勾选，恢复鼠标穿透。
- **“不透明度”**：拖动滑块调整面板透明程度。

面板仅在游戏或助手位于前台时显示，切到其他程序后会隐藏。主菜单和加载过程中不显示通关结论。

## 判定与提示

- 完美通关只取同一次最终结算的击杀率 100% 和秘密全收集。
- 当前已生成敌人的击杀比例仅为进度参考，不能预告最终整关击杀率。
- 位置提示为直线方向和距离，可能隔着墙或楼层，不是可通行路线。
- 未加载区域、无法确认状态的秘密和未激活波次显示待核实。
- 数据超过两秒未更新后，停止将旧内容作为实时提示。
- 历史最高成绩不参与本次最终判定。统计未验证时不输出完美通关结论。

## 独立与卸载

所有插件文件、配置和日志留在插件文件夹，不向游戏目录安装文件，不写游戏配置或存档。
关闭助手只关闭显示面板；完整停止加载器需退出游戏。退出游戏后可删除整个插件文件夹。
更新后如果提示游戏里仍是旧版插件，请重启游戏再连接。不使用热卸载或强行替换运行中的加载器。

更新时先退出游戏和助手，再将新运行包解压到新文件夹并启动。个人面板设置保存在原插件目录的 `data/settings.json`，需要保留时可将它复制到新目录的对应位置。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 解压后找不到 `BoltgunCompletion.exe` | 检查下载的是 `win-x64.zip`，而不是源码包；重新完整解压 |
| 提示“未找到一代游戏主程序” | 通过“选择游戏”选择上文所示的游戏安装根目录 |
| 提示“请先启动一代游戏” | 启动游戏后再点击“连接游戏”；同时只运行一个一代游戏实例 |
| 提示“此游戏版本尚未适配” | 当前游戏构建不在支持范围内；请在 Issues 提供游戏构建号和提示文字 |
| 连接后看不到面板 | 勾选“显示悬浮面板”，切回游戏，并检查是否为窗口化或无边框模式；可勾选“允许拖动面板”在助手前台调整位置 |
| 提示文件缺失或校验失败 | 重新下载并完整解压运行包，保留全部目录结构 |
| 提示无法连接游戏进程 | 确认游戏和助手在同一用户、相同权限级别下运行 |
| 提示已加载其他位置的 UE4SS | 退出游戏，停用其他 UE4SS 加载器后重新启动，再连接本助手 |
| 显示“数据中断”或一直等待有效数据 | 旧数据显示已停止；若加载结束后仍未恢复，退出游戏和助手后重新启动并连接 |

仍有问题，可到 **[Issues](https://github.com/manbomanbo666/BoltgunCompletion/issues)** 提供助手版本、游戏构建号、报错文字和复现步骤。提交日志前请移除其中的个人路径等信息。

## 从源码构建

环境：Windows x64、CPython 3.12 x64、.NET Framework 4.x C# 编译器。构建脚本使用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`。

```powershell
python tools/fetch_dependencies.py
python tools/build.py
python tools/package.py
```

首次获取依赖需要联网。UE4SS 固定为 `3.0.1-1181-g83330635`，下载包通过 SHA256 校验，缓存到 `work/`；缓存可删除并重新生成。构建使用仓库内的关卡元数据，不需要重新扫描游戏文件。

输出位于 `dist/`：

- `BoltgunCompletion/`：可直接运行的插件目录。
- `BoltgunCompletion-0.1.0.1-win-x64.zip`：供用户下载的运行包。
- `BoltgunCompletion-0.1.0.1-source.zip`：干净源码包。
- `SHA256SUMS.txt`：两个压缩包的 SHA256。

已有自动检查保留在源码中，可按需运行：

```powershell
python tests/test_runtime.py
dist/BoltgunCompletion/BoltgunCompletion-cli.exe --selftest
```
